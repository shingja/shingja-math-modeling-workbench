## 调用架构(v0.1.0)

### 加载链(触发后按需渐进加载, 不一次全读)

```
触发(关键词: 数学建模/CUMCM/Linger/代理模型/联合校准...) 
  → 主 SKILL.md (193行: 路由表+12大类+6门禁+目录结构, 唯一入口)
      ├── 角色层: references/roles/{Linger,Tide,Gloom}/SKILL.md → 各自 references/ 子文件
      ├── 协议层: joint_calibration / model-to-code-handoff / Subagent调度 / frozen_numbers / decision_log / interactive_mode
      ├── 经验层: references/lessons/ 12文件 (见下方"实战经验库")
      ├── 算法层: references/paradigms/ 161卡 + INDEX + keyword_router + assets/09说明 + matlab/ 228 .m
      ├── 工具层: tools/ (docx/latex/pdf/xlsx/paper_search/evaluate/joint_calibrate/handshake_validate/result_claim_bind/model_ensemble_select / model_quality_score)
      └── 门禁层: gates/ C1/W1/W2 (.m, 硬门禁) + M1/P1/P2 (Subagent质检, 软门禁)
```

### 加载器路径(保证调用到最新版)

- skills\ 目录下唯一 `math-modeling`; 顶层 SKILL.md 与嵌套 shim `skills/math-modeling/SKILL.md` 版本一致(v0.1.0), 加载器无论走哪条路径都命中同一版本
- 版本准据: `VERSION` 文件 = 0.1.0(frontmatter/plugin.json/shim 六处同步, 有 test_skill_integrity.py 自动检查)
- 历史版本以 git 提交为准(仓库 `shingja/shingja-math-modeling-workbench`), 回退用 `git log` 定位后 `git checkout <commit> -- <路径>`; 旧机器时代的离线备份已随旧机退役, 仅作存档参考

### 门禁链(四段全流程的质检节点)

```
Linger完成 → M1(软) → Tide首次跑通 → P1(软) → C1联合校准(硬, calibration_score三档 + 指标达成度D6)
  → 代码冻结 → P2(软, 含提交包干净目录重跑) → Gloom证据大纲 → W1(硬) → 论文终检 → W2(硬, 电子版/纸质版双模式)
  → 提交打包 S1 检查(lessons/提交包规范.md)
```

## 六、训练模式与评估（v2.0 新增）

### 训练模式

非比赛期间**默认为 T1 竞赛级**质量标准。完整执行所有步骤+验证。如要降低标准：

```
降级到T2。完整建模。题目路径：D:\...\选题A\
```

### 自动评估

训练模式下每个阶段完成后**自动触发评估**。也可手动触发：

```

```
