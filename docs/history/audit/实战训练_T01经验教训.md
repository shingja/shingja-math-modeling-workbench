## 一、Bug发现与修正记录 (4个)

### Bug 1: 碰撞检测几何建模不完整 ⭐⭐⭐
- **问题**: 板凳矩形仅覆盖把手间距离(孔间距), 未延伸至实际板头(孔到板头27.5cm×2)
- **影响**: Q2碰撞时刻: 441.0s→412.5s(偏差29s, 6.9%); Q3最小螺距: 36.6→42.1cm(偏差19%)
- **根因**: 几何建模只到连接点, 未到物理边界
- **修正**: `p1_ext = p1 - 0.275*u, p2_ext = p2 + 0.275*u`
- **教训**: 任何物理实体的几何建模, 必须从最外边界开始, 不是从连接点开始
- **防范**: M1门禁应增加"几何建模完整性"检查项: 确认所有物理边界已覆盖

### Bug 2: Q4入口策略未与论文对齐 ⭐⭐
- **问题**: 默认在r=4.5m边界处开始调头, 论文A016在r=4.41m(98%边界)
- **影响**: Q5最大速度: 1.522→1.449m/s(偏差22%→3%)
- **根因**: 未查阅论文的具体入口策略
- **修正**: CompositePath支持entry_theta覆盖, frac=0.98
- **教训**: 多阶段问题中, 上游建模选择的微小差异在下游被放大(入口2%→Q5 22%)

### Bug 3: 变量名遮蔽 ⭐
- **问题**: `np`同时作为`import numpy as np`和局部变量`new_positions`的缩写
- **影响**: 运行时`AttributeError: 'numpy.ndarray' object has no attribute 'linalg'`
- **修正**: 重命名为`new_p`
- **教训**: Python代码审查必须检查变量名冲突

### Bug 4: 论文格式不满足2026官方规范 ⭐
- **问题**: 页边距2.54/3.18cm, 无专用摘要页, 含英文摘要
- **规范要求**: A4/2.5cm四边, 专用摘要页(仅中文≤1页), 正文≤30页
- **修正**: 全文重建至2026规范

## 二、方法论积累

### M1: 三级交叉验证体系
```
L1 (本地论文): Tesseract 5.4 + chi_sim 30MB → OCR扫描件PDF
L2 (联网搜索): WebSearch site:csdn.net → 思路+代码+数值
L3 (自复算): SHA-256哈希绑定 → 确定性复现
```
**关键**: L1/L2不可用时必须如实标记, 不做虚假比对。

### M2: 几何建模的物理边界原则
- 板凳长方形 = 孔间距 + 两端各27.5cm延伸
- 盘出螺线 = 中心对称像E(θ)=-P(θ), 非θ+π偏移(差bπ/圈)
- S曲线 = 入口/出口切线C¹连续, 非简单圆弧拼接

### M3: Q4→Q5参数传播分析
入口策略(frac)是Q5偏差的首要来源:
- frac=1.00 (边界): v_max=1.522 (偏差22%)
- frac=0.98 (A016): v_max=1.449 (偏差3%)
- frac=0.85 (A053): v_max≈0.69 (偏差更大)
**规则**: 所有可调参数必须做灵敏度扫描, 记录参数→结果映射

### M4: 代码模块化标准
```
src/
├── modules/
│   ├── core.py      共享核心(物理常量/螺线/链约束/碰撞)
│   ├── q1_basic_coiling.py
│   ├── q2_collision.py
│   ├── q3_min_pitch.py
│   ├── q4_s_curve.py
│   └── q5_max_speed.py
└── main_modular.py   编排器
```

### M5: 论文2026官方规范12条
1. A4纸, 2.5cm四边 2. 专用摘要页(仅中文≤1页) 3. 正文≤30页
4. 无身份信息 5. 附录含源码 6. 文件≤20MB 7. 无占位符
8. 摘要含具体数值 9. 参考文献规范 10. 图表编号连续 11. 公式可编辑 12. 双格式一致
