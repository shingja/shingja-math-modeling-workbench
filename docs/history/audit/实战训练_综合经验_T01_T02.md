# 第一部分: 两类题型的共性与差异

## 题型对比

| 维度 | T01 板凳龙 (机理建模) | T02 古代玻璃 (统计+ML) |
|------|------|------|
| 核心方法 | 阿基米德螺线+链式约束+碰撞检测 | K-means+VotingClassifier+卡方检验 |
| 数据特征 | 零数据(纯数学模型) | 66样×14维成分数据 |
| Bug模式 | 几何建模不完整(物理边界) | 聚类k值选择差异(建模选择) |
| 交叉验证 | 5篇论文数值直接对比(偏差<3%) | 4篇论文准确率对比(100%一致) |
| 关键经验 | 物理边界→几何完整性 | 硬指标(准确率)优先于软指标(k值) |
| OCR质量 | 良好(数学公式PDF) | 中等(表格密集PDF) |
| MATLAB | 自定义数学函数 | Statistics Toolbox |

## 共性规律

1. **交叉验证是唯一真理**: 两题均通过L1论文比对发现/确认问题
2. **方法选择有优劣, 但不存在唯一正确答案**: T01的5条Q4/Q5路线, T02的k=3~8选择
3. **OCR是基础设施**: T01 OCR质量好→深度纠察可行; T02 OCR受限→只能确认方法/准确率
4. **三阶段skill路由有效**: Linger→Tide→Gloom 三阶段均有明确产出标准

# 第三部分: 执行准则 (v2.0)

基于T01+T02双题实战, 更新执行准则:

1. **建模前**: 验证L1数据源(OCR可用), L2搜索可达, L3自复算框架就绪
2. **建模中**: 几何建模从最外物理边界开始(P); 数据驱动先做EDA检查(P)
3. **建模后**: 可调参数做灵敏度扫描, 标注下游参数传播影响
4. **比对时**: L1/L2/L3均需真实数据; 不可用标记N/A, 不做虚假比对
5. **编码时**: 默认模块化结构; 变量名避免与导入冲突; MATLAB双语言可选
6. **论文前**: 先读当届官方规范, 逐条对齐; 嵌入全部图表; 摘要含具体数值
7. **软硬指标**: 硬指标(准确率/数值偏差)必须一致; 软指标(k值/参数选择)标注合理性
8. **交付时**: Linger3文件, Tidesrc+results+figures+3门禁, Gloom完整论文+W1/W2
