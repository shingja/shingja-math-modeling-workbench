### 环境约束说明

本轮 R1-b 尝试了三种 OCR 路径均受阻:
1. `pdftotext -l 2` → 空返回 (确认纯扫描版, 无隐藏文本层)
2. `pdftoppm` → 二进制不可用 (WSL/MinGW 环境未安装 poppler-utils)
3. `tesseract` → Python wrapper 已安装但二进制不在 PATH
4. `fitz.Page.get_text()` → 0 chars (无文本层)
5. Read 工具 → 对 PNG/JPG 返回 "Unsupported Image"

建议: 在 S4/S5 的独立阶段中, 用户可在本地安装 poppler-utils + tesseract 后重新 OCR 这 23 篇, 或手动补充四元组。当前已将文件名线索+题型知识推断的算法方向填入, 满足"绝不放弃"的 D1 要求。
