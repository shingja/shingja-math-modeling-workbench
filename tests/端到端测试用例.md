## 测试用例 1：2025 CUMCM C 题 — NIPT 时点选择与胎儿异常判定

**题型**：数据统计 + 分类决策
**对应培训**：模块 14-21（数理统计）、模块 25-26（机器学习）

### 问题摘要

孕妇外周血中胎儿游离 DNA（cffDNA）浓度随孕周增加而上升。NIPT（无创产前检测）需要在 cffDNA 浓度足够高时采样才能保证检测准确性。题目给出一批孕妇的多时间点 cffDNA 浓度数据，要求：
1. 建立 cffDNA 浓度随孕周变化的数学模型
2. 确定 NIPT 最佳采样时间窗口
3. 基于多指标综合判定胎儿异常风险

### Skill 工作流验证步骤

#### Linger
1. 读取 `2025年/C题/C题.pdf` 及附件数据
2. 输出 `题目分析报告.md`：识别子问题类型（回归预测 + 分类评价 + 时间窗口优化）
3. 输出 `术语表格.md`：cffDNA、NIPT、孕周、假阳性率等术语定义
4. 推荐模型组合：
   - 子问题 1：非线性回归（Logistic 增长）+ 灰色预测 GM(1,1)（对比）
   - 子问题 2：蒙特卡洛模拟确定阈值 + 动态规划时间窗口
   - 子问题 3：BP 神经网络分类 + ROC 曲线评估

#### Tide（MATLAB 验证）
1. 检查环境：`check_matlab_env.m` 验证 Statistics and ML Toolbox、Curve Fitting Toolbox
2. 从 `LOCAL_ALGO_ROOT` 加载：
   - `9、非线性回归分析/logist.mlx` → cffDNA 浓度生长曲线拟合
   - `10、灰色预测分析/case1.mlx` → 趋势对比
   - `12、蒙特卡洛算法/` → 阈值模拟
   - `25、机器学习-神经网络/ann.mlx` → 风险分类
3. 运行并输出：
   - 拟合曲线图（SVG + PNG, 300 DPI）
   - ROC 曲线图（含 AUC 值）
   - 最佳采样时间窗口表格（CSV）
4. 生成 `复现清单.json`：rng(42,'twister')、数据文件 SHA-256、MATLAB R2024a

#### Gloom
1. 基于官方模板生成论文
2. 摘要必须包含：Logistic 模型 R² 值、最佳采样窗口（具体孕周范围）、分类 AUC 值
3. 三线表格式结果表
4. 自审通过：公式可编辑、图表编号连续、参考文献双向对应

### 预期结果
- Linger交付 2 个 .md 文件
- Tide交付 ≥ 3 个 .m 文件 + ≥ 3 张图 + 1 个 CSV
- Gloom交付 1 个 .docx 论文（≤ 30 页正文）

### 通过条件
- [x] MATLAB 代码全部可运行（`run('main.m')` 无错误）
- [x] 模型选择符合"每子问题 ≤ 2 个独立模型"约束
- [x] 摘要包含具体数值结果
- [x] 图表使用非默认色板
- [x] 复现清单完整

## 测试用例 2：2024 CUMCM A 题 — "板凳龙"闹元宵

**题型**：力学/几何建模 + 数值模拟
**对应培训**：模块 12（蒙特卡洛）、模块 27（机理建模）

### 问题摘要

"板凳龙"是一种由多节板凳连接而成的传统表演道具。表演者手持板凳在固定路径上运动。题目要求：
1. 建立板凳龙各节的空间位置和速度模型（螺旋线路径）
2. 分析相邻板凳之间的碰撞条件
3. 确定不发生碰撞的最大表演速度
4. 优化板凳龙的转弯路径

### Skill 工作流验证步骤

#### Linger
1. 读取 `2024/A题/A题.pdf` 及 3 个附件
2. 输出 `题目分析报告.md`：识别问题类型为几何建模 + 碰撞检测 + 优化
3. 输出 `术语表格.md`：阿基米德螺旋线、曲率半径、链式约束、碰撞检测
4. 推荐模型组合：
   - 子问题 1：阿基米德螺旋线参数方程 + 链式运动学约束（ODE）
   - 子问题 2：几何碰撞检测（最小距离法）
   - 子问题 3：二分搜索优化最大速度
   - 子问题 4：双圆弧转弯曲线 + 曲率连续约束

#### Tide（MATLAB 验证）
1. 检查环境：`check_matlab_env.m` 验证 Optimization Toolbox
2. MATLAB 实现（无直接培训代码，需从 Python/理论翻译）：
   - 螺旋线轨迹生成 → `spiral_trajectory.m`
   - 链式运动学仿真 → `chain_dynamics.m`
   - 碰撞检测 → `collision_detect.m`
   - 二分搜索速度优化 → `speed_optimize.m`
   - 双圆弧转弯 → `dual_arc_turn.m`
3. 参考教材第 13-15 章（ODE 建模与求解）获取理论依据
4. 输出：轨迹动画图、碰撞安全区域图、速度-安全裕度曲线（SVG + PNG）

#### Gloom
1. 基于官方模板生成论文
2. 摘要必须包含：最大安全速度（具体数值）、转弯优化后的路径长度缩短百分比
3. 公式使用 OMML 格式（阿基米德螺旋线、链式约束方程）

### 预期结果

- Tide：MATLAB 代码从理论推导实现（验证翻译能力）

## 测试用例 3：2023 CUMCM C 题 — 蔬菜类商品自动定价与补货决策

**题型**：数据分析 + 优化决策
**对应培训**：模块 1-6（评价类）、模块 7-9（回归）、模块 22-24（优化）

### 问题摘要

某生鲜超市销售多种蔬菜，需要根据历史销售数据制定每日定价和补货策略。题目给出各蔬菜品类的历史销售流水（含销量、价格、损耗率），要求：
1. 分析蔬菜品类间的销售关联性和时间分布规律
2. 建立销量-价格关系模型，确定最优定价
3. 在满足市场需求的前提下，制定最小化损耗的补货策略
4. 给出未来一周的定价和补货建议

### Skill 工作流验证步骤

#### Linger
1. 读取 `2023/C题/C题.pdf` 及 4 个附件（Excel 销售数据）
2. 输出 `题目分析报告.md`：识别子问题类型（关联分析 + 回归 + 优化）
3. 输出 `术语表格.md`：损耗率、补货周期、定价弹性、品类关联
4. 推荐模型组合：
   - 子问题 1：灰色关联分析（品类间关联度）+ 熵权法（销售时段权重）
   - 子问题 2：多元线性回归（销量-价格弹性模型）
   - 子问题 3：整数规划（补货量优化，最小化损耗）
   - 子问题 4：遗传算法或 PSO 求解多目标优化（利润 + 损耗）

#### Tide（MATLAB 验证）
1. 检查环境：`check_matlab_env.m` 验证 Optimization Toolbox、Global Optimization Toolbox
2. 从 `LOCAL_ALGO_ROOT` 加载：
   - `5、灰色关联分析/code1.m` + `code2.m` → 品类关联分析
   - `3、熵权法/Entropy_Method.m` + `mylog.m` → 时段权重
   - `8、多元线性回归分析/HousePricing.mlx` → 价格弹性模型
   - `23、智能优化-遗传优化/Matlab/` (Sheffield GATBX) → 多目标优化
3. 读取附件 Excel → 使用 `tools/xlsx/` 工具
4. 输出：关联度热力图、价格-销量散点图+拟合线、补货策略对比表（CSV）

#### Gloom
1. 基于官方模板生成论文
2. 摘要必须包含：价格弹性系数、优化后的损耗率降低百分比、预期利润提升
3. 结果表使用三线表
4. 灵敏度分析：价格弹性系数 ±20% 扰动

### 预期结果
- Linger：数据驱动的模型选择（附件数据量决定模型复杂度）
- Tide：MATLAB 代码 + Sheffield GATBX 工具箱调用
