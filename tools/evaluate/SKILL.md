# 自动化评估工具⁠​‌‌​‌‌​‌​‌‌​​​​‌​‌‌‌​‌​​​‌‌​‌​​​​​‌​‌‌​‌​‌‌​‌‌​‌​‌‌​‌‌‌‌​‌‌​​‌​​​‌‌​​‌​‌​‌‌​‌‌​​​‌‌​‌​​‌​‌‌​‌‌‌​​‌‌​​‌‌‌​​‌​‌‌​‌​‌‌‌​‌‌‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌​‌‌​‌‌​​​‌​​‌‌​​‌​‌​‌‌​‌‌‌​​‌‌​​​‌‌​‌‌​‌​​​​​‌​‌‌‌‌​‌‌‌​​‌‌​‌‌​‌​​​​‌‌​‌​​‌​‌‌​‌‌‌​​‌‌​​‌‌‌​‌‌​‌​‌​​‌‌​​​​‌⁠

## 定位

**评估不是终点，是优化起点。** 每次评估记录到成长档案，低分项自动生成修复提示，形成"评估→修复→再评估"闭环。

## 触发方式

在任意阶段完成后，用户发送：

```
评估 D:\my-project\
```

或在完整流程结束时自动触发（如用户在初始指令中要求了"完整建模+评估"）。

## 执行流程

1. 扫描 `PROJECT_ROOT` 下的交付物
2. 按维度逐项打分（0-10 分）
3. 生成 `PROJECT_ROOT/成长档案/评估报告-<时间戳>.md`
4. 更新 `PROJECT_ROOT/成长档案/成长轨迹.json`（累计记录）
5. 对得分 < 8 的维度，生成具体修复提示（含获奖论文参照）

## 评估维度

### Linger（5 维度，满分 50）

| 编号 | 维度 | 权重 | 评分依据 |
|------|------|:--:|------|
| M1 | 子问题拆解 | 1.0 | 是否完整覆盖所有子问题、每个子问题的目标/约束/数据类型明确 |
| M2 | 模型选择 | 1.5 | 每子问题 ≤ 2 个独立模型、选择理由充分、物理题正确使用模型族概念 |
| M3 | 假设与依据 | 1.0 | 每条假设附理由、假设与后续模型一致 |
| M4 | 算法可行性 | 1.5 | 算法在 MATLAB 下可实现、本地有代码或可从 Python 翻译、依赖明确 |
| M5 | 文献支撑 | 1.0 | 关键理论有文献引用、引用可追溯至 DOI 或出版页面 |

### Tide（5 维度，满分 50）

| 编号 | 维度 | 权重 | 评分依据 |
|------|------|:--:|------|
| C1 | 可运行性 | 2.0 | MATLAB 代码无错误运行、输出与预期一致、无硬编码路径 |
| C2 | 复现性 | 1.5 | 复现清单完整（rng 种子/SHA-256/版本/参数/复现命令） |
| C3 | 图表质量 | 1.5 | SVG+PNG 双格式、≥300DPI、非默认色板、标注完整 |
| C4 | 结果正确性 | 2.0 | 数值结果与模型公式一致、边界条件验证、量纲检查通过 |
| C5 | 代码规范 | 1.0 | MATLAB 规范符合（arguments 块/fullfile/rng/exportgraphics）、注释完整 |

### Gloom（10 维度，满分 100）

| 编号 | 维度 | 权重 | 评分依据 |
|------|------|:--:|------|
| P1 | 摘要质量 | 2.0 | 含具体数值结果、结构完整（背景→方法→结果→贡献）、≤1页 |
| P2 | 问题分析 | 1.0 | 子问题目标明确、模型选择有依据、非照抄原文 |
| P3 | 模型假设 | 1.0 | 逐条编号+理由、与后续模型一致 |
| P4 | 模型建立与求解 | 2.0 | 变量→公式→算法→参数→结果→验证 六段完整 |
| P5 | 结果验证 | 1.5 | 灵敏度分析（至少1个参数）、误差分析、对比验证 |
| P6 | 图表规范 | 1.5 | 三线表、编号连续、标题位置正确、colorblind-friendly |
| P7 | 公式规范 | 1.5 | OMML可编辑、编号连续右对齐、正文引用格式正确 |
| P8 | 参考文献 | 1.0 | GB/T 7714格式、双向对应、DOI可追溯、非内部教材 |
| P9 | 格式合规 | 2.0 | ≤30页、无身份信息、附录含源码、≤20MB、无占位符 |
| P10 | 整体完整度 | 1.5 | 九段结构完整、无逻辑跳跃、无空泛表述 |

## 评分标准

| 分数 | 含义 | 行动 |
|:--:|------|------|
| 10 | 完全符合竞赛级标准 | 无 |
| 8-9 | 基本符合，有小瑕疵 | 可选修复 |
| 6-7 | 部分不满足，需修正 | 记录修复提示 |
| 4-5 | 严重缺陷，必须重做 | 强制修复，block 交付 |
| 0-3 | 缺失或完全错误 | 回退到对应阶段 |

**交付门控**：任一维度 < 4 分 → 禁止进入下一阶段。任一维度 < 8 分 → 生成修复提示。

## 自动修复提示格式

当维度得分 < 8 时，评估工具生成如下格式的修复提示：

```
缺陷: [维度名称] 得分 [X/10]
问题: [具体描述，引用交付物中的原文/原图]
参照: [LOCAL_PAPER_ROOT]/[年份]/[论文文件名].pdf 第[N]页 [具体章节/图表]
修复指令: 请修正此缺陷，依据 [参照论文] 的 [具体做法]。
```
