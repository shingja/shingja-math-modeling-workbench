## 一、Linger交付物标准

Linger完成分析后，必须提供以下内容。按质量级别（T1/T2/T3）决定粒度。

### 1.1 变量映射表

| 数学符号 | 代码变量名 | 物理含义 | 单位 | 类型 | 默认值 |
|---------|-----------|---------|------|------|--------|
| $\alpha$ | `alpha` | 学习率 | — | double | 0.01 |
| $N$ | `n_population` | 种群规模 | 人 | int | 1000 |
| $\lambda$ | `lambda_decay` | 衰减系数 | 1/day | double | 0.05 |

**要求**：
- T3：口头确认关键变量（≥5个）
- T2：表格 ≥15 行，覆盖所有模型参数
- T1：完整表格 + 每个变量标注来源（题目给定/假设/文献引用/数据估计）

### 1.2 算法伪代码

语言无关步骤描述，Tide可直接转译为 MATLAB/Python。

**格式规范**：
```
算法名称：<名称>
输入：<参数列表及类型>
输出：<返回值列表及类型>

步骤：
1. <步骤描述>。若 <条件>，则 <分支行为>。
2. FOR i = 1 TO N:
       <循环体>
   END FOR
3. WHILE <收敛条件不满足>:
       <迭代体>
   END WHILE
4. RETURN <输出>
```

**边界条件与异常处理**（必须注明）：
- 输入为空时：返回空列表，不报错
- 除数为零：分母 < 1e-12 时，返回 +Inf 并记录警告
- 迭代不收敛：超过 max_iter 时返回当前最佳解，warning 标记

### 1.3 参数约束

| 参数 | 取值范围 | 类型 | 默认值 | 灵敏度 | 说明 |
|------|---------|------|--------|--------|------|
| alpha | (0, 1] | double | 0.01 | 高 (±0.005) | >0.5 时震荡，<0.001 时收敛极慢 |
| max_iter | [50, 1000] | int | 200 | 低 | 超过 500 后改善不显著 |

**要求**：
- T3：口头说明取值理由
- T2：完整约束表 + 默认值
- T1：T2 + 灵敏度关键参数标记 + 文献支持

### 1.4 验证用例

至少 1 组手工可算的小规模输入及预期输出。

**示例**：
```
输入: X = [1, 2, 3], y = [2, 4, 6]
预期: 回归系数 beta = [0, 2]  (截距=0, 斜率=2)
容差: |beta - [0, 2]| < 1e-10
```

**要求**：
- T3：口头描述 1 组
- T2：至少 1 组手算可验证的用例，含输入/预期输出/容差
- T1：≥2 组用例，覆盖正常/边界/异常三类

## 二、Tide反馈标准

Tide实现后，必须向Linger反馈以下内容。

### 2.1 实现偏差说明

| 模型假设 | 代码实现 | 偏差 | 原因 |
|---------|---------|------|------|
| 连续时间 SIR | 离散 Euler 步进 dt=0.1 | 离散化误差 | 无解析解，数值求解必要 |
| 无穷级数截断 | 截断到前 20 项 | 截断误差 < 1e-6 | 验证：第 21 项 < 1e-8 |

**若偏差影响模型结论**：立即反馈Linger，不自行修改模型。

### 2.2 数值稳定性报告

| 检查项 | 结果 | 处理 |
|--------|------|------|
| 矩阵条件数 | 1.2e8（病态） | 使用 pinv（SVD 伪逆）替代 inv |
| 梯度消失 | 第 50 轮梯度 < 1e-10 | 调整激活函数为 ReLU |
| 浮点溢出 | log(0) → -Inf | 加 epsilon=1e-12 |

### 2.3 性能瓶颈

| 瓶颈 | 耗时 | 占比 | 优化建议 |
|------|------|------|---------|
| 三重 for 循环 | 120s | 85% | 向量化，或 parfor 并行 |
| 大矩阵求逆 (5000×5000) | 45s | 32% | 改用迭代法 (pcg) 或降维 |

### 2.4 交叉验证结果

Linger验证用例的代码运行结果：

| 用例 | 预期输出 | 实际输出 | 误差 | 通过 |
|------|---------|---------|------|:----:|
| 回归 X=[1,2,3] y=[2,4,6] | beta=[0,2] | beta=[2.3e-16, 2.0] | <1e-10 | ✅ |
| 边界 N=1 | p=[1.0] | p=[1.0] | 0 | ✅ |

| 交付物 | T3 生存级 | T2 标准级 | T1 竞赛级 |

| — | | | |

## 四、交接检查清单

### Linger交付前（自查）
- [ ] 对照题目检查：所有符号与题目数据字段对应
- [ ] 每个公式右侧变量在变量表中可查
- [ ] 伪代码不依赖 MATLAB/Python 特定语法
- [ ] 验证用例输入输出由手算/教科书确认
- [ ] T2/T1 级别交付物写入 `题目分析报告.md` 或独立 `模型握手交付包.md`

### Tide启动前（接收检查）
- [ ] 变量映射表可全部映射为代码变量
- [ ] 伪代码可直接翻译（无歧义步骤）
- [ ] 参数约束不违反代码语言特性
- [ ] 验证用例可在本地环境运行
- [ ] 缺项时：列出缺失清单 → 反馈Linger → 不猜测、不编造
