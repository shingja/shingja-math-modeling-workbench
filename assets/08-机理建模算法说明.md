## 概述

机理建模基于对系统内部机制的理解，通过微分方程、差分方程等方法建立数学模型。与数据驱动的统计/机器学习方法不同，机理模型强调对因果关系的数学表达，具有更强的可解释性和外推能力。

## 1. 人口增长模型 (Population Growth Models)

### 算法介绍

人口增长模型是机理建模的经典案例，通过微分方程描述人口随时间的变化规律。

#### 1.1 Malthus 指数增长模型

假设人口增长率与当前人口成正比：

$$
\frac{dN}{dt} = rN
$$

**解析解**：

$$
N(t) = N_0 e^{rt}
$$

**参数**：
- $N_0$：初始人口
- $r$：净增长率（出生率 - 死亡率）

**局限性**：在资源充足时适用，无法描述增长减缓或达到饱和的情况。

#### 1.2 Logistic 阻滞增长模型

引入环境容量（环境承载力）$K$：

$$
\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)
$$

**解析解**：

$$
N(t) = \frac{K}{1 + \left(\frac{K}{N_0} - 1\right)e^{-rt}}
$$

**关键特征**：
- $N \ll K$ 时接近指数增长
- $N = K/2$ 时增长率最大
- $N \to K$ 时增长趋于零
- 曲线呈 S 形（Sigmoid）

#### 1.3 Leslie 矩阵模型（年龄结构）

考虑年龄结构的离散时间模型：

$$
\mathbf{N}(t+1) = \mathbf{L} \cdot \mathbf{N}(t)
$$

其中 $\mathbf{L}$ 是 Leslie 矩阵：

$$
\mathbf{L} = \begin{bmatrix}
f_1 & f_2 & \cdots & f_{m-1} & f_m \\
s_1 & 0 & \cdots & 0 & 0 \\
0 & s_2 & \cdots & 0 & 0 \\
\vdots & \vdots & \ddots & \vdots & \vdots \\
0 & 0 & \cdots & s_{m-1} & 0
\end{bmatrix}
$$

$f_i$ 为年龄 $i$ 的生育率，$s_i$ 为年龄 $i$ 到 $i+1$ 的存活率。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 人口预测 | 区域人口预测 | 封闭系统 |
| 资源管理 | 渔业资源管理 | 环境容量 |
| 生态建模 | 种群动态 | 种间竞争 |
| 市场渗透 | 新产品扩散 | S 形增长 |

### 代码实现要点

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

def logistic_growth(N, t, r, K):
    """Logistic 增长模型微分方程"""
    dNdt = r * N * (1 - N / K)
    return dNdt

def solve_logistic(N0, r, K, t_span, n_points=200):
    """求解 Logistic 增长模型"""
    t = np.linspace(t_span[0], t_span[1], n_points)
    N = odeint(logistic_growth, N0, t, args=(r, K))
    return t, N.flatten()

def leslie_matrix(survival_rates, fertility_rates):
    """构建 Leslie 矩阵"""
    n = len(survival_rates)
    L = np.zeros((n, n))
    L[0, :] = fertility_rates
    for i in range(n - 1):
        L[i + 1, i] = survival_rates[i]
    return L

def leslie_project(L, N0, n_periods):
    """Leslie 矩阵投影"""
    N = np.zeros((len(N0), n_periods + 1))
    N[:, 0] = N0
    for t in range(n_periods):
        N[:, t + 1] = L @ N[:, t]
    return N

def fit_logistic(t_data, N_data, p0=None):
    """用最小二乘法拟合 Logistic 模型"""
    from scipy.optimize import curve_fit

    def logistic_func(t, K, r, t0):
        return K / (1 + ((K / N_data[0]) - 1) * np.exp(-r * (t - t0)))

    if p0 is None:
        p0 = [N_data[-1] * 2, 0.1, t_data[0]]

    popt, pcov = curve_fit(logistic_func, t_data, N_data, p0=p0, maxfev=10000)
    return popt, pcov
```

## 2. 传染病模型 (Epidemic Models)

### 算法介绍

传染病模型通过仓室模型描述疾病在人群中的传播动态。

#### 2.1 SIR 模型

将人群分为三个仓室：易感者 (S)、感染者 (I)、康复者 (R)。

$$
\begin{aligned}
\frac{dS}{dt} &= -\beta \frac{SI}{N} \\
\frac{dI}{dt} &= \beta \frac{SI}{N} - \gamma I \\
\frac{dR}{dt} &= \gamma I
\end{aligned}
$$

**基本再生数**：

$$
R_0 = \frac{\beta}{\gamma}
$$

- $R_0 > 1$：疾病爆发
- $R_0 < 1$：疾病消亡

**参数**：
- $\beta$：传播率（有效接触率）
- $\gamma$：恢复率（$1/\gamma$ 为平均感染期）
- $N = S + I + R$：总人口（常数）

#### 2.2 SEIR 模型

在 SIR 基础上增加潜伏期仓室 (E, Exposed)：

$$
\begin{aligned}
\frac{dS}{dt} &= -\beta \frac{SI}{N} \\
\frac{dE}{dt} &= \beta \frac{SI}{N} - \sigma E \\
\frac{dI}{dt} &= \sigma E - \gamma I \\
\frac{dR}{dt} &= \gamma I
\end{aligned}
$$

**参数**：
- $\sigma$：潜伏期到发病期的转化率（$1/\sigma$ 为平均潜伏期）

#### 2.3 SIS 模型

适用于康复后无免疫力的疾病（如流感）：

$$
\begin{aligned}
\frac{dS}{dt} &= -\beta \frac{SI}{N} + \gamma I \\
\frac{dI}{dt} &= \beta \frac{SI}{N} - \gamma I
\end{aligned}
$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 疫情预测 | 传染病趋势预测 | 封闭或半封闭人群 |
| 防控策略 | 疫苗接种策略评估 | 政策仿真 |
| 信息传播 | 谣言/信息扩散 | 类似传播机制 |
| 创新扩散 | 新技术/产品采纳 | S 形采纳曲线 |

### 代码实现要点

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

def sir_model(y, t, N, beta, gamma):
    """SIR 模型"""
    S, I, R = y
    dSdt = -beta * S * I / N
    dIdt = beta * S * I / N - gamma * I
    dRdt = gamma * I
    return [dSdt, dIdt, dRdt]

def seir_model(y, t, N, beta, gamma, sigma):
    """SEIR 模型"""
    S, E, I, R = y
    dSdt = -beta * S * I / N
    dEdt = beta * S * I / N - sigma * E
    dIdt = sigma * E - gamma * I
    dRdt = gamma * I
    return [dSdt, dEdt, dIdt, dRdt]

def solve_epidemic(model_func, initial_conditions, params, t_span, n_points=200):
    """求解传染病模型"""
    t = np.linspace(t_span[0], t_span[1], n_points)
    solution = odeint(model_func, initial_conditions, t, args=params)
    return t, solution

def calculate_r0(beta, gamma):
    """计算基本再生数"""
    return beta / gamma

def estimate_beta_gamma_from_data(t_data, I_data, N, S0, I0, R0):
    """从数据估计 beta 和 gamma 参数"""
    from scipy.optimize import minimize

    def loss(params):
        beta, gamma = params
        t, sol = solve_epidemic(
            sir_model, [S0, I0, R0],
            (N, beta, gamma),
            (t_data[0], t_data[-1]),
            len(t_data)
        )
        I_pred = sol[:, 1]
        return np.mean((I_pred - I_data) ** 2)

    result = minimize(loss, [0.3, 0.1], bounds=[(0.01, 1.0), (0.01, 0.5)])
    return result.x[0], result.x[1]
```

## 3. 常微分方程建模 (ODE Modeling)

### 算法介绍

许多机理问题可建模为常微分方程或方程组。求解方法分解析法和数值法。

#### 3.1 数值求解方法

**Euler 法（一阶）**：

$$
y_{n+1} = y_n + h \cdot f(t_n, y_n)
$$

**Runge-Kutta 4 阶法（RK4）**：

$$
\begin{aligned}
k_1 &= h \cdot f(t_n, y_n) \\
k_2 &= h \cdot f(t_n + h/2, y_n + k_1/2) \\
k_3 &= h \cdot f(t_n + h/2, y_n + k_2/2) \\
k_4 &= h \cdot f(t_n + h, y_n + k_3) \\
y_{n+1} &= y_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{aligned}
$$

#### 3.2 参数估计（ODE 拟合）

已知系统结构和部分观测数据，估计 ODE 参数：

1. 定义 ODE 系统（含待估参数）
2. 设定参数初始值
3. 数值求解 ODE
4. 计算预测值与观测值的误差
5. 优化参数使误差最小

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 动力学建模 | 化学反应动力学 | 反应速率方程 |
| 物理建模 | 力学系统、热传导 | 物理定律驱动 |
| 生态建模 | 捕食者-猎物模型 | Lotka-Volterra 方程 |
| 经济建模 | Solow 增长模型 | 宏观经济动态 |

### 代码实现要点

```python
import numpy as np
from scipy.integrate import solve_ivp

def lotka_volterra(t, y, alpha, beta, delta, gamma):
    """Lotka-Volterra 捕食者-猎物模型"""
    prey, predator = y
    d_prey = alpha * prey - beta * prey * predator
    d_predator = delta * prey * predator - gamma * predator
    return [d_prey, d_predator]

def solve_ode_system(ode_func, y0, t_span, params, method='RK45'):
    """求解 ODE 系统"""
    sol = solve_ivp(
        ode_func, t_span, y0,
        args=params,
        method=method,
        dense_output=True,
        rtol=1e-6, atol=1e-9
    )
    return sol

def fit_ode_parameters(ode_func, t_data, y_data, y0, param_bounds, n_params):
    """拟合 ODE 参数"""
    from scipy.optimize import differential_evolution

    def objective(params):
        sol = solve_ivp(
            ode_func,
            [t_data[0], t_data[-1]],
            y0,
            args=tuple(params),
            t_eval=t_data,
            method='RK45'
        )
        if not sol.success:
            return 1e10
        return np.mean((sol.y.T - y_data) ** 2)

    result = differential_evolution(objective, param_bounds)
    return result.x
```

## 4. 差分方程模型 (Difference Equation Models)

### 算法介绍

差分方程描述离散时间系统中的变量递推关系。

#### 一阶线性差分方程

$$
x_{n+1} = ax_n + b
$$

**稳态**：$x^* = \frac{b}{1-a}$（当 $|a| < 1$ 时稳定）

#### Logistic 离散模型

$$
x_{n+1} = rx_n(1 - x_n)
$$

**混沌行为**：当 $r > 3.57$ 时系统进入混沌状态。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 离散动态 | 世代重叠不连续的种群 | 离散时间步 |
| 经济周期 | 蛛网模型 | 供需延迟 |
| 控制系统 | 离散时间控制器 | 采样系统 |

## 5. 偏微分方程建模 (PDE Modeling)

### 算法介绍

偏微分方程用于描述空间和时间上连续变化的系统。

#### 5.1 扩散方程

$$
\frac{\partial u}{\partial t} = D \frac{\partial^2 u}{\partial x^2}
$$

#### 5.2 波动方程

$$
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}
$$

#### 5.3 有限差分法 (FDM)

**一维扩散方程离散化**（显式格式）：

$$
\frac{u_j^{n+1} - u_j^n}{\Delta t} = D \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{(\Delta x)^2}
$$

**稳定性条件**：$\frac{D\Delta t}{(\Delta x)^2} \leq \frac{1}{2}$

### 代码实现要点

```python
import numpy as np

def solve_diffusion_1d(D, L, T, nx, nt, u0_func, bc_left, bc_right):
    """一维扩散方程有限差分解"""
    dx = L / (nx - 1)
    dt = T / nt

    # 检查稳定性
    r = D * dt / dx**2
    if r > 0.5:
        print(f"Warning: r = {r:.3f} > 0.5, solution may be unstable")

    x = np.linspace(0, L, nx)
    u = np.zeros((nt + 1, nx))
    u[0, :] = u0_func(x)

    for n in range(nt):
        u[n + 1, 1:-1] = u[n, 1:-1] + r * (
            u[n, 2:] - 2 * u[n, 1:-1] + u[n, :-2]
        )
        u[n + 1, 0] = bc_left
        u[n + 1, -1] = bc_right

    return x, np.linspace(0, T, nt + 1), u
```

### 按问题类型选择

| 问题类型 | 推荐模型 |
|---------|---------|
| 人口/种群动态 | Logistic、Leslie、Lotka-Volterra |

### 与数据驱动方法的比较

| 特征 | 机理模型 | 数据驱动模型 |
|------|---------|------------|
| 可解释性 | 高（物理意义明确） | 低到中 |
| 外推能力 | 强（超出训练范围仍有效） | 弱 |
| 数据需求 | 少（只需估计参数） | 多 |
| 建模难度 | 高（需要领域知识） | 低到中 |
| 精度 | 中（简化的现实） | 高（在训练范围内） |
| 适用场景 | 物理/生物/工程系统 | 缺乏物理知识的系统 |

## 6. 降维NS+能量方程流体-热耦合模型 (Reduced-Order NS+Energy for Fluid-Thermal Systems)

> **v2.0 新增** | 模块路径: `PROJECT_ROOT/algorithms/ns_energy_reduced/ns_energy_module_v1.0.py`
> 题型感知关键词: `芯片热管理` `微通道散热` `液冷` `热管理系统` `对流换热` `压降` `温度均匀性` `散热器优化`

### 算法介绍

降维NS+能量方程模型从Navier-Stokes方程和能量方程出发，通过工程适用的简化假设（层流、不可压缩、常物性），利用经典解析解和关联式替代全3D CFD仿真，实现微通道散热系统的快速性能预测。

#### 6.1 物理基础

控制方程经降维后使用以下经典关联式闭合：

**流动摩擦因子 (Shah & London, 1978)**:
$$f \cdot Re = 96(1 - 1.3553\alpha^* + 1.9467\alpha^{*2} - 1.7012\alpha^{*3} + 0.9564\alpha^{*4} - 0.2537\alpha^{*5})$$

**充分发展Nusselt数 (Shah & London, 1978, Table VII.4)**:
采用5点分段线性插值，覆盖α*∈[0,1]：
| α* | 0 (平行平板) | 0.125 | 0.25 | 0.5 | 1.0 (方形) |
|----|-----------|-------|------|-----|----------|
| Nu (UHF) | 8.235 | 5.597 | 4.439 | 3.391 | 3.091 |

**热发展流修正 (Hausen关联式)**:
$$\overline{Nu} = Nu_{fd} + \frac{0.0668 \cdot Gz}{1 + 0.04 \cdot Gz^{2/3}}, \quad Gz = Re \cdot Pr \cdot \frac{D_h}{L}$$

**同时发展流 (Sieder-Tate关联式)**:
$$\overline{Nu} = \max\left(1.86\left[\frac{Re \cdot Pr}{L/D_h}\right]^{1/3}, Nu_{fd}\right)$$

**水力网络流量分配 (Commenge et al., 2011)**:
并联管路中第i分支流量与阻抗成反比：
$$Q_i = Q_{total} \cdot \frac{1/Z_i}{\sum_j 1/Z_j}$$
其中 $Z_i = Z_{ch,i} + Z_{man,in}^{(i)} + Z_{man,out}^{(i)}$，歧管损失系数采用Bassiouny & Martin (1984)位置依赖模型。

#### 6.2 模块架构


1. NS模块输出物理量(R_physical, DP_physical, theta_physical)
2. 线性校准后得到无量纲预测值
3. 校准模型可作为问题二中GPR/RF/RSM的**物理先验**: 将NS预测值作为GPR的均值函数m(x), 而非默认的常数均值
4. 或在问题二的输入特征中增加NS预测值作为第4维特征

问题一→问题三/四的衔接: NS模块计算得到的Re、Nu、Φ可直接输入优化模型作为约束条件或初始解引导。
