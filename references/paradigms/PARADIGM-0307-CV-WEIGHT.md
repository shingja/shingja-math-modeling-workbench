## 数学形式

### 1. 计算各指标的均值和标准差

设有 m 个样本, n 个指标, 原始数据矩阵 $X = (x_{ij})_{m \times n}$.

$$\mu_j = \frac{1}{m} \sum_{i=1}^m x_{ij}, \quad \sigma_j = \sqrt{\frac{1}{m-1} \sum_{i=1}^m (x_{ij} - \mu_j)^2}$$

### 2. 计算变异系数

$$CV_j = \frac{\sigma_j}{|\mu_j|}$$

**解释**: CV 是标准差对均值的归一化, 表示单位均值上的离散度, 消除了量纲和数量级的影响.

### 3. 归一化得权重

$$w_j = \frac{CV_j}{\sum_{j=1}^n CV_j}$$

权重的经济学解释: 变异系数越大的指标, 在样本间差异越大, 包含的区分信息越多, 应赋予更大权重.

**复杂度**: 空间 O(n), 时间 O(mn) — O(mn) 扫描一次计算均值和方差.

## MATLAB 实现

```matlab
% ===== PARADIGM-0307-CV-WEIGHT: 自写-见S5:cv_weight.m =====
function [w, CV, mu, sigma] = cv_weight(X)
    % X: m×n 原始数据矩阵 (样本×指标)
    % w: 1×n 变异系数权重向量
    % CV: 1×n 各指标变异系数
    % mu: 1×n 各指标均值
    % sigma: 1×n 各指标标准差

    [m, n] = size(X);

    % --- 计算均值与标准差 ---
    mu = mean(X, 1);
    sigma = std(X, 0, 1);  % 样本标准差 (除以 m-1)

    % --- 计算变异系数 ---
    CV = zeros(1, n);
    eps_val = 1e-8;

    for j = 1:n
        if abs(mu(j)) < eps_val
            warning('指标 %d 均值接近零 (mu=%.2e), CV 趋于无穷, 赋权失效. 建议对该指标单独处理.', ...
                j, mu(j));
            CV(j) = sigma(j) / eps_val;  % 占位, 实际不可用
        else
            CV(j) = sigma(j) / abs(mu(j));
        end
    end

    % --- 归一化得权重 ---
    if sum(CV) < eps_val
        error('所有变异系数之和接近零, 无法赋权. 请检查数据.');
    end
    w = CV / sum(CV);

    % 输出摘要
    fprintf('\n=== 变异系数法赋权结果 ===\n');
    fprintf('%-6s %-12s %-12s %-8s\n', '指标', '均值', '标准差', '权重');
    for j = 1:n
        fprintf('%-6d %-12.4f %-12.4f %-8.4f\n', j, mu(j), sigma(j), w(j));
    end
end
```

## Python 备选

```python
import numpy as np

def cv_weight(X: np.ndarray) -> tuple:
    """变异系数法客观赋权 (纯 numpy)"""
    m, n = X.shape

    mu = X.mean(axis=0)
    sigma = X.std(axis=0, ddof=1)  # 样本标准差

    eps_val = 1e-8
    CV = np.zeros(n)
    for j in range(n):
        if abs(mu[j]) < eps_val:
            CV[j] = sigma[j] / eps_val
        else:
            CV[j] = sigma[j] / abs(mu[j])

    w = CV / CV.sum()

    return w, CV, mu, sigma
```

## 常见坑

1. **均值接近零导致 CV 爆炸**: 若某指标的均值 μ_j ≈ 0 (如温度数据经中心化/归一化后), CV = σ/|μ| → ∞, 该指标权重趋向 1, 其余指标权重 →0. 这是 CV 法最致命的缺陷. **必须在计算前检查所有指标均值, 均值绝对值 < 某个阈值 (如 0.01) 的指标改用其他赋权方法.**
2. **方差与均值同步增长 (比率稳定)**: 若两个指标 A 和 B 的 CV 相同 (如均为 0.3), 但 A 的均值和标准差均为 B 的 10 倍, CV 法无法区分它们的重要性 — 这可能是合理的 (两者相对离散度相同), 也可能是误导的 (A 的绝对差异远大于 B). 取决于业务判断.
3. **CV 独立性假设**: CV 法 (同熵权法) 假设指标间相互独立. 若 3 个高度相关的指标的 CV 均较大, 三者各获得独立权重, 但在综合评价中这三个指标的效应被重复计入 (三重计). 应在赋权前做相关分析 or PCA 降维.
4. **小样本 CV 偏差**: 样本标准差在小样本 (m<10) 下有系统偏差 (低估). 若需精确, 可使用偏差修正: CV_corrected = (1 + 1/(4m)) × CV_raw.
5. **CV 法对异常值的敏感性**: 一个异常极端值同时拉大 σ 和 μ. 若异常值在均值同方向, σ 和 μ 同步放大, CV 可能变化不大 (抵消). 但在实际评价中, 该异常值不应获得如此大的"影响力". 应先做异常值处理.

## 失效条件/反例 (强制小节)

- **条件1 — 均值接近零 (|μ_j| < 1e-6)**: 变异系数定义为 σ/|μ|, 是一个比率统计量. 当分母趋近于零时, CV 发散至无穷. 典型场景: 对零均值指标 (如 GDP 增长率经去均值处理后的残差) 或二进制指标 (0/1 编码, 均值可能接近 0) 使用 CV 法赋权. 结果: 该指标 CV → ∞, w_j → 1, 其余指标权重 → 0, 赋权完全失效. 处理: 改用熵权法 (PARADIGM-0303) 或 min-max 归一化后直接用标准差赋权.
- **条件2 — 方差与均值相互抵消 (CV 近似零)**: 某指标在所有样本中方差极大 (如 GDP 的 σ = 5万亿), 但均值也极大 (μ = 50万亿), CV = 0.1. 同时另一指标的方差和均值都小, CV=0.1. 两者获同等权重. 但 GDP 的绝对差异 (万亿级) 对评价体系的影响远大于第二个指标 (百万级), CV 的相对化处理抹平了这一关键区别. 在"绝对水平重要"的评价场景 (如经济实力) 中, CV 法可能产生严重误判, 应改用标准差异加权或主成分赋权.
- **条件3 — 指标间高度相关导致权重膨胀**: 三个业务上高度相关的指标 (人均 GDP、城镇居民人均可支配收入、农村居民人均可支配收入) 各有 CV≈0.3. CV 法独立赋权给三者合计约占 40%~50% 的总权重, 实际相当于"收入"这一维度被放大了 3 倍. 赋权前必须检查 VIF (方差膨胀因子), VIF>5 的指标应合并或降维.

## 来源溯源

变异系数 (CV = σ/μ) 作为相对离散度的度量最早由 Karl Pearson 于 1896 年引入, 后由 Snedecor & Cochran 在其经典教材《Statistical Methods》中系统性地推广为标准的描述性统计量. CV 的优势在于消除了量纲和尺度的影响, 使不同数量级的指标之间的离散度可以直接比较. 将 CV 归一化后用作 MCDM 中的权重是 CV 在中国综合评价文献中的自然延伸 — 取"指标区分度 = 权重"的信息论原则, 用变异系数度量区分度, 归一化即得权重. CV 法与熵权法并列为两种最常用的客观赋权方法, 其区别在于 CV 法基于矩 (均值和方差), 熵权法基于分布 (概率密度).
