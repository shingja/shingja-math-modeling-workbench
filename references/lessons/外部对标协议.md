## 二、逐维对比矩阵(论文冲刺期)

| ... | | | |

## 三、偏离二分法(差异归类)

我方与外部方案不一致时, 先把差异归类:
- **设计性偏离**: 我方有意为之且可论证更优(如"外推区不取最优"、诚实 CV)
- **缺陷性偏离**: 我方确实可能错了(触发红色警报, 回模型复查)

争议裁决实例(抽象化模板):
1. 量化验证: 训练数据在争议区域样本数为 0(数据拓扑)
2. 距离证据: 最近样本距争议点有明显距离
3. 误差证据: 代理模型在该区域外推误差显著偏大
4. 物理验证: 内点方案全指标优于边界基线
→ 裁决: 外部边界取值是外推伪影, 我方内点是真实最优。防御段落定量化。
