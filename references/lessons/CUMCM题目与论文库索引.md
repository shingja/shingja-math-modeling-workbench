## 三、优秀论文写作范式提炼(样本 5 篇, 每篇 3 条)

样本选取原则: 有文本层、覆盖机理/优化/统计三大主流题型、跨 2017-2023 年份。全部数据由脚本实测(页数/图表编号上限/参考文献/章节标题)。

### 样本1: 2023A 定日镜场(A092.pdf, 53页, 图≤36, 表≤8, 参考文献3篇)

- 摘要: 约 500 字, 结构 = 背景一句话 + "针对问题一/二/三"逐问叙述(每问: 用什么模型→关键方法→得到什么数) + 结尾不写结论只收束。关键词 5 个(光学效率/蒙特卡洛算法/单目标优化/遗传算法/年平均输出热功率), **关键词与正文方法一一对应**。
- 章节: 一问题重述 → 二模型假设 → 三符号说明 → 四问题分析 → 五模型的建立与求解(内含模型求解/模型检验) → 六模型的评价改进与推广 → 七参考文献 → 附录1-15(15个附录, 代码+结果文件清单+关键代码全文)。
- 参考文献 3 篇: 学位论文[D] + 学位论文[D] + 期刊[J], 全部中文、全部与题目技术领域强相关(塔式光热), 格式 GB/T 7714。

3 条可复制范式:
1. **"逐问五要素"摘要句式**: 针对问题X, 先[物理量求解路径]再[关键算法]最后[具体数值结果]——每问固定嵌入至少 1 个数字(该文摘要含 2739块镜、年平均功率等数值), 数值密度是摘要得分点。
2. **物理量→效率链的"分项建模"写法**: 光学效率拆成 5 个分项(镜面反射率/大气透射率/余弦效率/阴影遮挡效率/截断效率), 每个分项一个小子节, 既有机理推导又有蒙特卡洛数值验证——分项越细, 机理可信度越高。
3. **附录分层**: 附录1=支撑材料文件清单(每个 .m 文件带一行注释说明用途), 附录2=关键代码全文, 附录3-15=补充图表——文件清单+注释代码的组合让评委 3 分钟复现, 是国一标配。

### 样本2: 2023C 蔬菜定价与补货(C050.pdf, 44页, 图≤35, 表≤17, 参考文献4篇)

- 摘要: 约 600 字, 问题一内部再分"第一问/第二问"叙述, 嵌入具体统计量名(标准差/偏度系数/峰度系数/Spearman相关系数/K-means++聚类)与结论(如"除茄类外均显著正相关"), 问题四收尾于"最优补货量和定价策略"。
- 章节: 一问题重述 → 二问题分析 → 三模型假设 → 四符号说明 → 五**数据侧写**(数据预处理专章) → 六~九"问题X模型的建立与求解"(每问独立成章) → 十模型的评价与推广 → 十一参考文献 → 十二附录。
- 图表: 35 图 17 表, 图以分布图/热力图/相关性图为主, 表以描述统计表/结果表为主; 附录2 专门放"补充表格、图片", 正文只保留结论性图表。

3 条可复制范式:
1. **"数据侧写"独立成章**(13 章论文模板的"5数据预处理"在国赛论文中同样成立): 每问建模前先做该问数据的统计画像(分布/相关性/聚类分层), 为后文模型选择提供证据链。
2. **每问独立成章 + 章内固定小节序**: 六~九每章 = 问题分析→模型建立→模型求解→结果分析, 与摘要"针对问题X"逐问对应——摘要与章节一一映射是国赛论文的隐形结构分。
3. **方法命名写进关键词**: 关键词=K-means++聚类/优化模型/模拟退火模型/灰色关联分析, 全部是正文实际使用的方法名, 无凑数词——关键词是"方法清单"不是"主题词清单"。

### 样本3: 2018A 高温作业服装(43页, 图≤17, 表≤3, 参考文献7篇)

- 摘要: 约 550 字, 开头一句"以Fourier定律和能量守恒定律为理论依据"点出物理根基, 逐问叙述时嵌入 PDE 细节(隐式向后差分/追赶法/三对角)与数值(偏差指数 0.4593, 最大误差 1.99)。
- 章节: 一问题重述 → 二问题分析(2.1/2.2/2.3 逐问分析) → 三模型假设 → 四符号说明与名词解释 → 五模型建立与求解(5.1.x~5.3.x 四级编号, 含"问题X模型的检验"和"灵敏度分析"小节) → 六模型评价(优点/缺点/改进方案三段) → 参考文献 → 附录一~五(每个附录=一道题的 matlab 程序)。
- 参考文献 7 篇: 学位论文 1 + 期刊 6, 覆盖热防护/热传导/冷却规律等本领域真实文献, 全部为模型的理论出处。

3 条可复制范式:
1. **摘要开篇亮"第一性原理"**: 第一句就说清模型的物理根基(Fourier 定律+能量守恒), 再用数值结果收束——机理题摘要的"理论依据+数值结果"两头硬, 中间过程简写。
2. **模型检验与灵敏度分析嵌在求解章内**(5.1.6 问题一模型的检验、5.2.4 灵敏度分析), 而不是放最后笼统说——每个子问题都"求解后立即检验"是机理题的高分习惯。
3. **符号说明合并"名词解释"**: 物理题专有名词(I/II/III/IV 层、边界条件类型)在符号表中给定义, 减少正文铺垫——符号表兼作术语表。

### 样本4: 2018B 智能RGV调度(99页, 图≤25, 表≤18, 参考文献6篇)

- 摘要: 约 500 字, 针对三种工况(一道工序/两道工序/故障处理)分别给出策略名("八步一走"调度模型/多步捆绑联动/故障排查概率分析), 策略**命名制**是该文特色。
- 章节: 一问题重述(含1.1问题背景 1.2系统作业参数) → 二问题分析 → 三模型假设 → 四符号说明 → 五模型的建立和求解(5.1一道工序/5.2两道工序/5.3随机故障, 各含工作原理→调度时间→优化模型→求解算法→结果→实用性) → **六模型的灵敏度分析(独立成章)** → 七模型的综合评价与推广 → 八参考文献 → 九附录。
- 附录: 开头注明程序运行环境(MATLAB版本/许可证/OS/Java版本)——可复现性声明是 2018 年起国一的标配。

3 条可复制范式:
1. **策略命名制**: 给核心调度策略起名("八步一走"/"多步捆绑联动"), 摘要、正文、结论统一用名——命名让评审记住你的方法, 也方便摘要写出方法创新点。
2. **三种工况平行结构**: 每种工况按"工作原理→调度时间→优化模型→求解算法→结果→实用性"完全平行展开——结构复读不是缺点, 平行结构是工程题的最优写法(评委按图索骥)。
3. **灵敏度分析独立成章(第六章)**: 与样本3(嵌入小节)形成对照——**算法型题目灵敏度独立成章, 机理型题目灵敏度嵌在各问**; 两种都是对的, 取决于题目是"参数敏感性"还是"物理量验证"主导。

### 样本5: 2017A CT系统标定(29页, 图≤20, 表≤3, 参考文献5篇)

- 摘要: 约 480 字, 无背景句, 直接"本文针对CT系统参数标定和未知介质信息的确定问题"开篇, 逐问给出方法与数值(探测器单元距离 0.2768mm 等精确到 4 位小数), 末句写新模板设计(改进项)。
- 章节: 一问题重述 → 二问题分析 → 三基本假设 → 四符号说明 → 五模型的建立与求解(5.1~5.6 六个子问题各含算法与求解) → 六模型的优缺点 → 七参考文献 → 八附录(附录一~八, 每附录=一道题代码)。
- 5.5 节"精度和稳定性分析"内嵌"模型求解五次, 求得的间距分别为 0.2767mm, 0.2768mm, 0.2768mm…"——**多次运行结果并列展示**证明数值稳定性。

3 条可复制范式:
1. **精度数据并列展示**: 同一参数多次求解结果并排列出(0.2767/0.2768/0.2768), 稳定性直接可见——比"结果稳定"四个字强百倍, 与 skill 数值卫生(种子固定+复跑)同源。
2. **改进项收尾**: 摘要与正文最后一节都落在"设计新模板改进标定精度"——每题在完成规定任务后追加一个自己的改进设计, 是拿"创新分"的标准动作。
3. **参考文献含方法出处**: 5 篇文献含 Wikipedia 条目(Projection-slice theorem)与算法原始文献——**每个非自明方法必须挂一篇出处**, 含在线资料, 引用格式 GB/T 7714 编号制。

### 范式提炼总结(与 13 章论文模板对比)
