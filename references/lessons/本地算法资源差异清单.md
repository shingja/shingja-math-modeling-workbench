## 三、建议增量并入清单(高优先级)

1. **EM 算法** (唯一全线缺失): 建 PARADIGM-0619-EM 卡 + assets/09 补条目 + 由 `算法资料/19、数理统计-参数估计/em.m` 或 `新1/22种机器学习/EM算法及其推广.ipynb` 移植 .m
2. **GA/SA 自实现 .m**: 由 gatbx 工具箱与 `24、模拟退火/Matlab/SA.m` 提炼 optim/genetic_algorithm.m、optim/simulated_annealing.m (现役只有内置函数锚点)
3. **回归三件套 .m**: 由 7/8/9 模块 ipynb 提炼 regression_linear.m (fitlm+诊断)、regression_nonlinear.m (lsqcurvefit/nlinfit+初值策略); 对应范式卡 0209-REGRESSION 系列
4. **假设检验 .m**: ttest_wrapper.m、chi2_test.m 并入 stats/ (现役只有 anova)
5. **Apriori 关联规则**: 由 `通用算法模块/modeling/apriori.py` 移植 apriori.m + 范式卡 (FP-Growth 已有卡 0617, 可同卡补充)
6. **蒙特卡洛 .m**: simulation/monte_carlo.m (积分/抽样/π估计), 卡 0701 已有锚点空缺
7. **手写 BP 网络**: 由 `25、机器学习-神经网络/ANN.py` 移植 ml/ann_backprop.m 或 Python 侧保留
8. **通用流水线 Python 侧**: `通用算法模块` 整包可作 skill 的 Python 工具箱引用 (HyperParamTuner/ModelEnsemble/SmartImputer), 弥补现役 Python 侧只有范式卡的短板
9. **Kaggle 3 流水线**: 作为 E/C 题完整流水线模板索引, 记入 lessons/ 供三阶段流程参考
10. **可视化**: 以 skill 可视化规范为准, 仅借鉴 seaborn 调色板对照表与 FacetGrid 教程 (详见下节)

### 可视化规范对比 (新1-Matplotlib-Seaborn vs skill Tide可视化规范)

| 维度 | 本地资源 (Matplotlib-and-Seaborn-master) | skill 现役规范 | 结论 |
|------|-----------------------------------------|---------------|------|
| 网格线 | seaborn 教程默认主题带 grid (darkgrid/whitegrid) | **默认不用网格线**, 参考线只用有数值意义的 xline/yline | 冲突: 以 skill 为准, 本地教程仅作 API 学习 |
| 调色板 | seaborn 六色板 deep/muted/pastel/bright/dark/colorblind | viridis/cividis/Okabe-Ito + cb_palette.m (Wong 2011) | 兼容: colorblind 与 Okabe-Ito 同源, 可对照映射 |
| 导出 | 教程未强调 | 300 DPI + SVG/PNG 双格式, 禁只用 show() | skill 规范更严, 本地无此要求 |
| 高级图型 | FacetGrid/REG/category/Heatmap 有专门教程 | figures/ 有 plot_heatmap.m 等 24 函数, 无 FacetGrid 教程 | 本地 FacetGrid 分面教程可补 figures/ 使用说明 |
| 中文字体 | 教程未覆盖 | assets 各说明均有中文字体多字体备选方案 | 本地缺, 不可照搬本地默认 |
