## 一、必披露清单(Gloom W1 证据大纲阶段逐项核对)

- [ ] 每个指标的验证口径: train/test 分开、CV 方案、样本量、seed; 训练集 R² 禁止冒充泛化性能
- [ ] 多输出指标分开报告: 禁止"平均 R²=0.99"掩盖低分指标(实战: 统一声称>0.99 被终审抓出)
- [ ] 代理模型 σ 语义: 预测 σ(认知) ≠ 制造/输入扰动 σ(物理), 公差分析用后者
- [ ] 外推区域显式标注: 训练域空白组合、优化解与训练域距离、外推方向与幅度
- [ ] 边界最优性: 变量贴上界/下界时用 KKT/灵敏度论证, 并声明"对代理模型验证"的局限
- [ ] 方法失败史: 试过的失败方法+失败原因+修复路径(GPR R²=-10.27 → 标准化 → 0.997)
- [ ] 模型局限: 每条配改进方向(不是"数据有限"式空话)
- [ ] 非单调/反直觉现象: 不抹平, 给机制解释（如物理耦合导致的非单调响应, 附补偿机制分析）
- [ ] 近似与假设的定量边界: 每条假设附定量辩护(辐射忽略: 1.1kW/m² vs 500kW/m²)
- [ ] 与外部方案的差异: 我方结论与他人不同时, 给数据拓扑/方法学根因

## 二、诚实性小节模板(正文内)

```
§X.Y 发现的普遍意义与诚实性声明
1. 失败案例: [方法] 在 [条件] 下失败([具体数值]), 根因 [诊断链], 修复 [方案], 修复后 [数值]
2. 成功与失败的对比揭示了 [方法学洞察] —— 这就是本文贡献之一
3. 本工作未解决的: [列表], 各自的影响边界
```

实例: "GPR 不做标准化 R²=-10.27 → 条件数>10¹² → StandardScaler+WhiteKernel → 0.997。该发现说明离散 CFD 数据上核方法的输入尺度敏感性远超文献常见预期…"

## 五、诚实披露与加分的关系(实战结论)

评审不看"我们多完美", 看"我们知道自己不完美在哪里"。
- 9/9 趋势验证: 从"R²=0.10 缺陷"重构为"9/9 定性验证 + 定量 R²(设计选择)"——诚实重构把弱点变加分
- RSS 8x 发现: 主动披露"我们的代理模型 σ 系统性低估制造 σ"反而成为 P7 加分章
- 外部方案 N=0: 主动承认并定量防御("己方最佳距外部最优的差距及原因")优于回避
- **M-Loop 迭代轨迹**(v4.2.0): metric_trajectory.json 记录"方案A不达标→诊断→方案B达标"全过程, Gloom在诚实性声明小节写成方法学洞察(如 "RSM 在 θ* 上 R²_test=0.42 → 诊断: 标量参数不足以表达三维效应 → GPR+标准化 → 0.991")。迭代失败路线也入论文(方法失败史), 藏失败 = 评委发现即重创。

## 六、方案对比分析节模板(v4.3.0, M-Loop 对比终局配套)

当多个方案被尝试后取其一, 论文增加"方案对比分析"小节(辅助证明), 写法:

```
§X.Y 方案对比分析
为验证最终方案的选择合理性, 我们共尝试 N 个方案:
- 方案A(库内/文献[Z]): 指标1=..., 指标2=...; 落选原因: [具体数值差距]
- 方案B(外部方法, 文献[W]): 指标1=..., 指标2=...; 落选原因: [复杂度/风险/指标]
- 方案C: 最终采用, 综合指标最优
对比表明: 最终方案在 [维度] 优于替代方案 [幅度], 该优势源于 [方法学根因]。
```

要点:
- 每个落选方案必须有**具体数值差距**(禁止"效果不好"空话)
- 外部引入的方法必须挂文献出处(DOI)
- 失败的尝试同样写(方法失败史), 评委对"试了N个方法"的严谨性买账
- 与方案对比表.md、metric_trajectory.json 数值一致
