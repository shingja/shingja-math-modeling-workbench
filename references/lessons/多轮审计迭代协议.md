> 来源: 实战冲刺期 R1-R60+ 轮审计迭代（自评分随轮次逐级上升）。
> 核心经验: **单轮聚焦 + 轮次登记 + 评分曲线收敛判定**, 而非一次大而全的审计。

## 一、为什么多轮 > 一轮

- 单轮审计只能看到最表层问题; 修复会引入新错误(实战: 摘要值序矛盾就是补丁引入新错误, R1-R4 又抓出来)
- 分数提升是阶梯式的: 每轮零点几分, 靠 60+ 轮稳步累积
- 轮次间必须重跑全部门控, 防止修复退化

## 二、轮次登记格式(每轮必记)

```
R{n} | 日期时间 | 聚焦维度(唯一) | 关键修复 | 分数(可选) | 引入的新风险
```

实战阶段示例:
- R1-R2 基础修复(全维度基线/外部对标+代码审计)
- R3-R6 质量深审(语言精炼/图表深审/统计严谨/交叉引用)
- R7-R8 代码与管线(语法+依赖/终审8项)
- R9-R12 数学深度增强(加权评分/提交锁定/GPR条件数证明/Morris)
- R13-R20 论文增强(数据合成/差距分析/论文统计/增强规划/条件数嵌入/显著性/保存/终审锁定)
- R21-R30 补充增强(FAST三方法收敛/章节定位/摘要密度/图表嵌入/综合对比/最终锁定)

## 三、单轮聚焦原则

- 每轮只聚焦 1 个维度(语言/图表/统计/交叉引用/代码/格式), 单维度深挖比多维度浅尝有效
- 每轮产出: 发现列表(带 file:line/页码) + 修复 + 重跑验证 + 分数变化
- 禁止在一轮内同时改论文正文和代码(交叉污染)

## 四、审计者池(实测有效的四类)

| 审计者 | 用法 |
|---|---|
| 10-reviewer 超级审计 | 10 个独立 reviewer 角色并行审稿, 每个从不同维度(数学/物理/统计/工程/写作/格式/规范/创新/诚信/表达), 汇总共识问题 |
| 8 身份 multipersona 审计 | 评委/导师/对手/新手读者/复现者/格式检查员/诚信审计员/竞赛教练 8 身份, 各出发现 |
| 对抗性审稿(7 遍) | 专门找"哪里能推翻结论": 数据真实性/复现性/最优性/统计口径/外推合法性 |
| 外部对标审计 | 朋友方案 + 公开方案逐维对比(见外部对标协议) |

## 五、评分与收敛

- 加权评分六维度: 数学严谨性/物理深度/方法多样性/结果完整性/写作质量/格式规范(权重自定并记录)
- 收敛条件: 连续 2 轮无新 P0/P1 发现 + 分数增幅 <0.1 → 锁定
- 锁定时必须: SHA-256 全量哈希 + 文件清单 + 时间戳(实战: 93 文件全量哈希)
- **锁定后再动任何文件 = 重新审计**

## 六、与角色流程的接法

- Gloom优化模式**取消"最多 2 轮"硬限制**, 改为按剩余时间预算: `可用轮次 = 剩余小时 × 1.5`, 每轮 ≤40 分钟
- 每轮结束写 decision_log 条目(见 decision_log_protocol.md), 记录"诊断深度": 证伪了方法 vs 没修好实现(实战教训: 移除某模型的决策数天后被翻案, 因为日志没区分"方法不行"和"实现没修好")
- W2 终检后仍可进入多轮审计(冲刺模式), 但每轮必须重跑 W2 门控

## 八、CV 题审计增补(CV 实战, v4.4.0)

CV 赛题终审按同一协议执行(复核审计报告: P0×4 / P1×11 / P2×20), 新增 CV 专属审计维度:

1. **数值三对齐**: 论文声明 ↔ 训练日志(results.csv/args.yaml) ↔ 提交 CSV, 逐数字溯源。典型发现: 论文写的微调 epoch 与实际不符(P1-1); 论文引用的 AP 值与 CSV 不一致(P1-2); 覆盖率三处口径不一致(P1-5)。
2. **方法名与代码实现对应**: "WBF 加权融合"但代码只 concat+权重未用(P0-3); "按严重度降序"但 set 迭代顺序输出(P0-4)——每个论文方法名都要在代码里找到真实现。
3. **图内数字与正文一致**: 改结论必须同步重生成图(实战: 图内百分比与正文不一致需重画)。
4. **附录代码 diff**: 逐字节比对附录与源文件(修复后全部逐字节全同)。
5. **渲染复核**: docx→PDF 渲染后核对页码/页脚域缓存/表格结构(实战: 发现 PAGE 域缓存值过期、表格重复列)。
6. **硬编码表格重跑风险**: organize 类脚本内嵌旧数值 → 重跑即与论文矛盾(实战 P1-7)——审计必须"脚本重跑输出 vs 交付 CSV"比对。
7. **环境与版本考古**: 训练史叙事必须与 args.yaml 一致(延训口径不一致, P1-3/4); 文档漂移时用 settings 白名单/日志反推实际命令。
