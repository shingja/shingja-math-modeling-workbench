1. 选用算法前必须核对假设、数据规模、目标、约束、验证方式和所需依赖
2. 每道子问题最多两个独立模型体系；同一物理机制的不同精度展开按一个模型族计数
3. 优先使用有 MATLAB 实现的算法；Python 代码翻译为 MATLAB 后使用
4. 复杂 ML 模型（LSTM、XGBoost 等）可在 MATLAB 不可行时使用 Python
5. 理论依据优先查教材（`LOCAL_TEXTBOOK_ROOT`），实现优先查本地代码（`LOCAL_ALGO_ROOT`）

## 题型感知自动推荐

Linger在分析题目时，若检测到以下关键词组合，应优先推荐对应的算法：

| 题目关键词 | 推荐算法 | 类别 | 优先级 |
|-----------|---------|------|--------|
| `芯片热管理` `微通道` `液冷` `散热器` `对流换热` `压降` `温度均匀性` | **降维NS+能量方程** (§08-机理 §6) + GPR代理 | 机理+代理 | **最高** |
| `热传导` `散热` `温度场` `热应力` | 扩散方程PDE / 降维NS+能量 (§08-机理 §5-6) | 机理 | 高 |
| `流体分配` `管网` `水力` `流量分配` | 水力网络 + 降维NS+能量 (§08-机理 §6) | 机理 | 高 |
| `传染病` `疫情` `SIR` `SEIR` | SIR/SEIR (§08-机理 §2) | 机理 | 高 |
| `人口预测` `种群` `Logistic` | Logistic/Leslie (§08-机理 §1) | 机理 | 高 |
| `多目标优化` `Pareto` `NSGA` | NSGA-II + TOPSIS (§01-优化 + §03-评价) | 优化 | 高 |
| `预测` `时间序列` `趋势` | ARIMA/GM(1,1)/LSTM (§02-预测) | 预测 | 中 |
| `评价` `排名` `权重` | AHP/熵权法/TOPSIS (§03-评价) | 评价 | 中 |
| `不确定性` `灵敏度` `鲁棒` `公差` | Sobol+Monte Carlo (§06-综合 + §08-机理 §6) | 验证 | 高 |

优先级: 最高=必须考虑, 高=强烈推荐, 中=可选增强。

**跨问题衔接**: 问题一用NS机理建模 → 问题二用NS预测值作为GPR均值函数(物理先验) → 问题三用NS的Re/Nu/Phi作为优化约束 → 问题五Sobol/MC基于NS模块。
