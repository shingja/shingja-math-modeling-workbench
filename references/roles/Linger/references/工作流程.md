## 一、读题与附件

1. 枚举题目、附件、数据表、图片和模板，记录文件哈希或明确版本。
2. 按子问题列出目标、约束、输入、输出和评价口径。
3. 检查数据字段、单位、缺失、异常、重复、时间顺序和空间关系。
4. 无法确认的事实写成待确认项，不自行补造。

## 二、理解后形成结论目标

先回答“题目要求最终说明什么”，再讨论模型。结论目标应描述输出类型和评价标准，不预写数值结果。

示例：

- 输出满足全部容量与时间窗约束的配送方案，并比较成本和稳定性。
- 输出未来各期预测及其不确定性，并用留出数据检验误差。

## 三、选择模型

每个子问题最多两个独立模型体系。模型数量包括主模型、并行对比模型或机理不同的串联阶段模型；灵敏度分析和误差检验不计作独立模型。

物理建模按“模型族”计数：若两光束干涉与多光束干涉共享同一物理机制和核心变量，只是反射阶次或精度不同，应视为同一模型族的基础版与扩展版。只有控制机理、状态变量、边界条件体系或求解目标发生实质变化时，才另计一个模型。

选择时逐项核对：

- 是否表达题目中的关键结构和约束。
- 数据是否满足模型假设。
- 是否能由 Python 或 MATLAB 可靠实现。
- 是否有清晰的验证方案。
- 创新是否来自题目结构、特征、约束、算法或验证，而非简单改名。

避免直接套用常见简单模型冒充创新；模型选择以问题适配、可验证和可实现为准。

## 四、搜索理论依据

按需读取 `../../../../tools/paper_search/SKILL.md`，使用 OpenAlex 与 AnySearch 两个引擎。优先保留 DOI 交叉匹配结果；标题匹配必须核对年份和作者。引用前检查原始出版页面。

### 4.1 论文-题目配对分析协议（强制）

引用或参考任何获奖论文时，必须执行以下配对分析，禁止脱离题目背景孤立读论文：

1. **定位论文**：从 `LOCAL_PAPER_ROOT/<年份>/` 读取目标论文 PDF。
2. **定位对应题目**：从论文文件名提取题型（A/B/C/D/E），导航到 `往届题目/<年份>/<题型>题/` 读取赛题原文 PDF。
3. **交叉验证**（至少完成以下 3 项）：
   - 论文解决的问题是否与题目要求一致？（防误配对）
   - 论文使用的模型是否适配题目给定的数据规模、约束条件和评价口径？
   - 论文的假设是否在题目条件下成立？（题目有特定约束而论文忽略 → 不可直接借鉴）
4. **提取可迁移要素**：仅提取在当前题目条件下可复用的方法论（建模思路、算法选择理由、验证方式），注明哪些要素依赖题目特定条件、不可直接迁移。
5. **记录溯源**：在 `题目分析报告.md` 的文献依据节中，标注每篇参考论文的年份、题型、论文编号，以及对应题目中验证过的约束条件。

配对路径规则：

```
论文: LOCAL_PAPER_ROOT/<年份>/<题型><编号>.pdf     (例: 2025年.../A196.pdf)
题目: 往届题目/<年份>/<题型>题/<题型>题.pdf          (例: 2025年.../A题/A题.pdf)
```

若题目 PDF 缺失（如较早年份仅有 DOC 格式），记录"题目原文不可用"并标注该论文的参考价值降级为"仅参考方法，无法交叉验证"。

## 五、写交付物

### `题目分析报告.md`

至少包括：

1. 题目与附件清单
2. 子问题拆解
3. 数据理解与预处理计划
4. 假设及依据
5. 每题模型与数学定义
6. 算法步骤、输入输出和验证方式
7. 编程依赖和候选图表
8. 风险与回退条件
9. 文献依据

### `术语表格.md`

至少包括中文术语、英文术语、符号、定义、单位、首次出现位置和禁止混用的近义词。

## 六、M1 独立验收

两个文件完成作者自检后立即冻结输入快照，并按 `../../../../protocols/Subagent调度.md` 派发未参与编写的质检 Subagent。`M1` 未返回 `PASS` 时不得进入编程；质检发现问题后由Linger修正，产物变化会使原回执失效，必须复验。
